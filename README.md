# Twisted Swann Studio

Preliminary website for **Twisted Swann Studio LLC**, handmade gemstone bonsai sculptures by Jamie Swann-Stojetz.

- Etsy: https://www.etsy.com/shop/TwistedSwannStudio
- Instagram: https://www.instagram.com/twistedswannstudio/

Single static page (`index.html`), no build step. Product photos load from the Etsy listings; each piece links to its Etsy listing for purchase. To update the collection, edit the `P` list near the bottom of `index.html` (listing id, title, price, Etsy image path).

Hosted with GitHub Pages: Live at https://sstojetz-art.github.io/twisted-swan-studio/ — Settings → Pages → Deploy from a branch → `main` / root.
